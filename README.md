# CCWiper

> 开源、免费、安全的 C 盘清理工具 —— **只归档，绝不删除**。

CCWiper 帮你找出 C 盘里的缓存、临时文件、日志、大文件和重复文件，**把它们移动到归档目录**，
而不是删掉。操作前弹出确认清单，操作后可一键撤销，全程本地运行，不上传任何数据。

---

## 30 秒上手

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动界面
python main.py
```

1. 点「扫描下载/桌面」或「浏览」选一个目录后点「扫描所选」
2. 在结果里勾选要清理的文件（受保护的系统文件已自动禁用勾选）
3. 点「归档选中」→ 确认清单 → 文件被移动到归档目录
4. 后悔了？点「一键撤销」全部搬回原处

---

## 核心特性

- **只归档不删除**：文件移动到 `~/.ccwiper/archive/`，原始目录结构保留，随时可还原
- **操作前确认清单**：每次归档都先弹出完整文件清单，逐条可核对
- **一键撤销**：所有移动记录在 `operations.jsonl`，一键全部回滚
- **安全规则引擎**：系统关键目录（Windows / Program Files / ProgramData 等）和
  可执行文件类型（.exe/.dll/.sys…）默认禁止操作，规则可在 `config/default_rules.json` 调整
- **智能分类**：缓存 / 临时 / 日志 / 大文件(≥1GB) / 下载 / 其他，并支持按内容 md5 找重复文件
- **完全本地**：不联网、不上传，隐私零风险
- **开源免费**：MIT 协议，代码可审计、可改、可再分发

## 安全承诺（这是本项目的底线）

| 承诺 | 说明 |
|---|---|
| 不删除 | 没有任何删除接口，最坏情况只是文件被挪了个位置 |
| 确认清单 | 任何变动前必须人工确认完整清单 |
| 一键撤销 | 一条日志，一处回滚 |
| 本地处理 | 零网络请求，零数据上传 |
| 可审计 | 全部源码开放，安全规则透明 |

> 市面上清理工具最被诟病的就是「误删文件 / 静默上传」。
> CCWiper 把这两点从设计上彻底堵死：删不掉，也传不出去。

```

├── core/

```

## 打包为单文件 exe（免安装分发）

想直接把 exe 发给别人、或自己双击用？项目自带 `build_exe.py`，一键打包成免安装单文件。

```bash
# 需要带 tkinter 的 Python（如系统 Python 3.12），managed 3.13 缺 tkinter 会失败
pip install customtkinter
python build_exe.py
# 产物：dist/CCWiper.exe （双击即跑，无需 Python 环境）
```

- `build_exe.py` 会自动安装 PyInstaller，用 `--onefile --windowed` 打包
- 包含 `config/default_rules.json`，打包后配置仍可正常读取
- `dist/`、`build/`、`*.spec` 已被 `.gitignore` 忽略，不会进仓库——exe 请本机生成，勿提交大文件
